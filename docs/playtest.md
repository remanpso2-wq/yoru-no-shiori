# プレイテストと公開前チェック

## 遊びの評価（未実施）

基本編と応用編を未プレイの協力者に試してもらう。事前に答えを教えず、操作説明だけ行う。

- 手がかりがどこにあるか、共有方法、ホストの役割を理解できたか
- 一人が答えを知るだけで終わらず、他の参加者にも推理の出番があったか
- 応用編の正解根拠に、別の妥当な組み合わせがないか
- ヒント前後の迷い、誤答後に何をすればよいか、所要時間、また遊びたいか
- 読みにくい文・不自然な前提・答えが露骨な箇所を記録する

所要時間表示は作者の目安で、測定済み平均ではありません。

## UI確認（未実施）

390px / 768px / 1440px、キーボードのみ、画面拡大200%、長い呼び名、全メモ表示。モーダルのEscape・フォーカス移動、応用編の根拠チェック、誤答表示、終了後の次の物語、ホスト引継ぎを確認。

## GitHub公開前

- ソース・README・既知の制限を揃える
- 新規リポジトリ上でロジック・型検査・ビルドCIを実行
- シークレット、Cookie、実DB、公開用でない検証入力が含まれないことを確認
- 利用ライセンスを決定する（未選定）

## ゲーム一般公開前

- 上記UI/プレイ評価、実際の複数端末での招待テスト
- リクエスト回数制限、期限切れ削除の定期実行、負荷・費用の確認
- 突然ホストが消えた場合の復旧、退出・参加者削除の設計
- AI出題は別の開発段階。固定問題版にAI利用と表示しない
