# 夜の栞 — Yoru no Shiori

仲間とひらく、小さな謎。オリジナル短編を1〜4人で解く協力ミステリーのポートフォリオです。

## v0.2で遊べること

- 5話の固定シナリオ（基本3話・応用2話）、ひとり／協力モード、10文字のルームコード
- 参加者ごとの証拠配布。共有されるまで他の参加者には本文を返さない
- 推理メモ、2段階のヒント、ホストによる解答、スコア、結末
- D1保存、2秒間隔のポーリング同期（非表示タブでは8秒）、同じブラウザからの復帰
- 状態バージョンを比較して更新するCAS方式で同時操作の上書きを防止

**AI出題は未接続です。** 現在の5問は固定されたオリジナル問題で、LLMは呼び出しません。
WebSocket方式ではなく短い間隔のHTTP同期です。切断中の操作は成功扱いせず、再接続後に状態を取り直します。

## 構成

React / TypeScript / Vinext / Cloudflare Workers / D1 / Drizzle。
`game/cases.mjs` はサーバー専用の問題バンク、`game/engine.mjs` は副作用のない状態遷移。
`app/api/game/route.ts` でCookie参加者認証・Origin検証・D1の条件付き更新を実施。

回答と解説は終了前のAPIレスポンスに含めません。問題ファイルをクライアントへimportしません。
ソース公開時は問題の正解も読めるため、競技用途の不正防止を保証するものではありません。

## 開発と確認

Node.js 22.13以上とpnpmを使用。`pnpm install` 後:

```sh
node --test tests/*.test.mjs
pnpm exec tsc --noEmit
pnpm run build
```

D1スキーマ変更時は `pnpm run db:generate`。生成済み移行は後から書き換えません。
デプロイはSitesのソース同期・ビルド・移行適用フローを利用します。
Sites以外に展開する場合はWorker/D1のデプロイ設定とアクセス制御を別途用意してください。

## 部屋とアクセス

最初は所有者限定の非公開Siteです。仲間と別端末で遊ぶにはSite自体のアクセス権設定が別途必要です。
部屋コードを知る人は開始前に参加可能。開始後は新規参加できません。
最初は作成者がホストで、開始・ヒント・解答を担当。待機中・プレイ中に他の参加者へ引継ぎ可能です。突然の切断からの自動引継ぎ・退出処理は未実装です。
参加者識別はHttpOnly / SameSite=Strict Cookie（HTTPSではSecure）、DBにはトークンのハッシュのみ保存。
同じブラウザプロファイルでは同一参加者になります。Cookieを消すと復帰できません。

部屋は24時間でアクセス不可。新規作成時に期限切れを最大10件削除します。
定期削除は未実装のため、無利用期間に期限切れデータが即時削除される保証はありません。
メモは各180文字・部屋あたり40件。個人情報や機密情報を入力しないでください。

## 次の実装

1. デプロイ先APIで複数セッション・並行操作・復帰を検証済み。次はブラウザE2E・視覚QA・実ユーザーによるプレイ評価
2. ホスト移譲は実装済み。ルーム離脱、自動引継ぎ、アクセシビリティの実機検証
3. AI生成: サーバーで構造化問題を生成→別工程で唯一解・矛盾・難易度を検証→人による承認後に出題
4. AIの失敗時も固定問題で遊べる構成。費用上限・回数制限・生成ジョブ・出題品質の評価セット
5. 一般公開前のIP/ユーザー単位制限、削除の定期処理、負荷試験

リアルタイム協力ゲームの土台を示す初版です。AI搭載済み・商用完成品とは位置付けていません。

## v0.2の遊びの改善

応用編「すり替わった展示札」「三番目の小包」を追加。結論だけでなく、根拠となる証拠2枚の組み合わせを判定します。未共有で読めない証拠は選べません。誤答後も残り回数と次の行動を表示し、終了後は根拠と解説から振り返れます。

操作IDによる再送制御を追加。部屋ごと直近64操作について、同一参加者・同一ID・同一内容の再送でヒントやメモ、解答を二重適用しません。内容の異なるID再利用は拒否します。ブラウザ再読み込み後はIDを保持しないため、先に同期された状態を確認してください。部屋作成の重複排除は対象外です。

## GitHub公開について

CI定義 `.github/workflows/quality.yml` を用意しています。GitHub側でのCIは、専用リポジトリへ反映後に確認が必要です。サイトは現在所有者限定で、ソースの公開とゲームへの一般アクセスは別の設定です。

秘密鍵・APIキー・実ユーザーデータは含めません。`.openai/hosting.json` のproject_idはこのSites配置の識別子です。第三者が複製する際は自分のSiteとして再登録してください。実行用環境ファイル、DB、認証トークンをコミットしないでください。

ソースの再利用ライセンスは未選定です。同梱テンプレートと依存ライブラリにはそれぞれのライセンスが適用されます。ゲームは架空の物語です。
